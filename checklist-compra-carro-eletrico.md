# Checklist de compra de carro elétrico ou híbrido

Use esta lista antes de fechar negócio:

[ ] Defini meu uso principal do carro  
[ ] Avaliei se rodo mais na cidade ou na estrada  
[ ] Entendi a diferença entre elétrico, híbrido e híbrido plug-in  
[ ] Verifiquei se tenho onde carregar  
[ ] Avaliei a instalação elétrica da casa ou condomínio  
[ ] Conversei com o condomínio, se aplicável  
[ ] Fiz cotação de seguro  
[ ] Consultei o IPVA no meu estado  
[ ] Calculei meu custo atual com combustível  
[ ] Simulei meu custo com energia  
[ ] Pesquisei concessionária ou assistência próxima  
[ ] Comparei versões e equipamentos  
[ ] Verifiquei garantia da bateria  
[ ] Entendi a autonomia real do modelo que me interessa  
[ ] Fiz test drive  
[ ] Li informações oficiais e manual, quando disponível  
[ ] Avaliei valor de revenda e mercado de usados  
[ ] Confirmei se o carro cabe no meu orçamento real  

## Se for usado ou seminovo

[ ] Verifiquei histórico de revisões  
[ ] Pedi laudo cautelar  
[ ] Conferi procedência  
[ ] Analisei estado dos pneus  
[ ] Confirmei cabos, carregadores, manual e chave reserva  
[ ] Investiguei sinais de colisão ou alagamento  
[ ] Testei a recarga, quando possível  
[ ] Consultei concessionária ou oficina especializada
